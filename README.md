# 스프링 AI 2.0 실습

『스프링 AI 2.0으로 배우는 AI 에이전트 개발 완벽 가이드』(허제민, 위키북스)를 장별로 따라가며 만든 **개인 학습용 실습 코드**다.
책의 흐름을 따르되 코드는 직접 작성했고, 처음 보는 사람도(나중의 나도) 이해할 수 있도록 주석을 자세히 달았다.

## 환경

| 항목 | 버전 | 비고 |
|---|---|---|
| Java | 21 | 스프링 AI 2.0은 17 이상, 21 권장 |
| Spring Boot | 4.1.1 | 스프링 AI 2.0은 Boot 4.x 필수 |
| Spring AI | 2.0.1 | 부모 `pom.xml`의 BOM 한 곳에서 관리 |
| 빌드 | Maven Wrapper (`./mvnw`) | Maven 설치 불필요 |
| 모델 런타임 | [Ollama](https://ollama.com/download) | 로컬 GPU/CPU로 오픈 모델 실행 |
| 채팅 모델 | `qwen3.5:4b` | 책의 기본 모델. 약 3.4GB |

## 시작하기

```bash
# 1) Ollama 설치 후 모델 받기 (한 번만)
ollama pull qwen3.5:4b

# 2) Ollama가 떠 있는지 확인 — 11434 포트
curl http://localhost:11434/api/tags

# 3) 장별 모듈 실행 (예: 1장)
./mvnw -pl chapter01 spring-boot:run

# 4) 모델 없이 도는 단위 테스트만 실행
./mvnw test
```

## 장별 구성

| 모듈 | 책 | 내용 |
|---|---|---|

각 모듈의 `README.md`에 그 장에서 무엇을 배우는지, 어떤 순서로 코드를 읽으면 되는지 적어 두었다.

## 구조 원칙

- 장마다 독립 실행되는 스프링 부트 앱 하나. 앞 장의 코드를 복사해 발전시키는 대신, 그 장의 개념에 집중한 최소 코드만 둔다.
- 테스트는 두 종류다.
  - 단위 테스트: 가짜 `ChatModel`로 모델 없이 돈다. `./mvnw test`로 언제든 실행.
  - 실제 모델 확인: `spring-boot:run`으로 로컬 Ollama에 직접 물어본다.
